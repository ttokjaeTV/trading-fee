## 감지만 합니다. 표를 자동으로 고치지 않습니다.

증권사 안내 페이지 중에는 오래된 값이 갱신되지 않은 채 남아 있는 곳이 있고, 이벤트 페이지는 본문이 이미지인 곳이 많습니다. 게다가 유관기관제비용 **포함/별도**나 계좌 종류·매체 구분처럼 **숫자만으로는 판단할 수 없는 맥락**이 요율 비교의 핵심입니다.

그래서 워커는 "뭔가 바뀌었다"까지만 알리고, 실제 갱신은 사람이 공식 안내를 확인한 뒤 실행합니다.

---

## ① 요율 지문

각 페이지에서 **요율로 보이는 수치(0.0005 ~ 0.95 사이 소수)** 를 뽑아 집합으로 비교합니다.
HTML 구조를 파싱하지 않으므로 마크업이 바뀌어도 잘 깨지지 않습니다.

> 수치 패턴은 주제마다 다릅니다. 수수료는 `0.0036396` 형태(`0\.[0-9]{2,7}`), 금리는 `2.45` 형태(`[0-9]\.[0-9]{1,2}`)입니다. `targets.json`의 `pattern` 값으로 전환합니다.

`tier: 1`은 대형사 요율 페이지입니다. 변하면 이슈 제목에 🚨가 붙습니다.

## ② 만료 캘린더

`deadlines.json`의 종료 예정일 기준으로 **D-14 / D-7 / 당일**에 알립니다. 지난 건도 30일까지는 "경과"로 계속 띄웁니다.

**갱신할 때 새 회차를 여기 반영하는 걸 잊지 마세요.** 목록이 낡으면 알림이 안 옵니다.

## 감시하지 않는 것

**환전 우대율과 신규계좌 이벤트** — 정작 변동성이 가장 높은 항목인데, 본문이 이미지이거나 회차마다 URL 자체가 바뀌어 자동 추적이 안 됩니다. 만료 캘린더가 이 공백을 부분적으로 메웁니다.

수치를 스크립트로 그리는 곳도 제외했습니다(수집값 0개).

**알림이 없어도 분기에 한 번은 전수 확인**이 필요합니다.
