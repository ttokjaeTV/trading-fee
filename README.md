# 증권사 수수료 비교표 (Brokerage Fee Comparison)

국내 13개 증권사의 **국내주식 수수료 · 미국주식 수수료 · 환전 수수료 · 신규계좌 이벤트**를 각 사 공식 수수료 안내에서 확인해 한 표로 정리한 단독 HTML 페이지.

🔗 **https://ttokjaetv.github.io/trading-fee/**

---

## 범위

- **지금 계좌를 새로 여는 경우** 기준
- 비대면 **일반 위탁계좌** · 온라인 주문 · KRX 체결
- 이벤트를 적용하지 않은 **표준 수수료**
- ❌ 제외: 연금저축 · IRP · 중개형ISA 등 절세계좌, 영업점 개설 계좌, 세금

> 이미 보유 중인 계좌는 과거 우대 이력 · 계좌 등급 · 개설 채널에 따라 요율이 달라 이 표가 그대로 적용되지 않는다.

---

## 구성

| 표 | 내용 |
|---|---|
| 01 | 종합 비교표 — 규모 · 국내 표기요율 · 국내 실부담 · 미국 매매 · 환전 · 이벤트 (정렬 가능) |
| 02 | 구간별 수수료 상세 (삼성 · 신한) |
| 03 | 조건부 무료 · 할인 제도 (적립식 · 소수점 · 계좌유형 · 환전) |
| 04 | 신규계좌 수수료 이벤트 상세 |
| 05 | 금액별 계산기 |
| 06 | 증권사별 공식 확인 링크 |

상단 검색창에 증권사명을 입력하면 모든 표에서 해당 행만 남는다.

---

## 파일

```
index.html          단독 HTML (외부 의존: Pretendard 폰트 CDN만)
data/2026Q3.json    데이터 스냅샷 — 다음 갱신 시 diff 기준
```

데이터는 `index.html` 상단 JS 객체(`SIZE` / `DOMESTIC` / `OVERSEAS` / `EVENTS` / `PERKS` / `LINKS`)에 모여 있다. **갱신 시 이 블록만 수정하면 된다.**

## 데이터 기준

- 확인일 **2026-08-19**, 각 증권사 공식 수수료 안내 · 이벤트 공지 직접 확인
- 회사 규모는 자기자본(연결), 2026년 반기보고서(DART). 토스 · 카카오페이는 비상장이라 2026.03.31 언론 보도 기준
- 환전 수수료는 각 사 공시 우대율을 **기준 스프레드 1% 가정**에 적용해 환산한 편도 값. 13개사 모두 원본 스프레드를 비공시해 회사 간 직접 비교에는 한계가 있다
- `확인필요` 표시는 공식 페이지에서 확인하지 못했거나 자료가 상충하는 항목

## 면책

정보 제공 목적의 비교표이며 특정 증권사 가입을 권유하지 않는다.
수수료율과 이벤트 조건은 수시로 변경되므로 실제 거래 전 해당 증권사 공식 안내를 확인할 것.
